## Rule 2 — Project Creation (Commands Only)

Never create project files manually. Always use official CLI tools.

### Web / MERN Projects
```bash
# Backend
mkdir -p backend/src/{controllers,models,routes,middleware,services,utils}
cd backend
npm init -y
npm install express@latest mongoose@latest dotenv@latest bcryptjs@latest jsonwebtoken@latest cors@latest helmet@latest
npm install -D nodemon@latest

# Frontend — always use Vite
npm create vite@latest frontend -- --template react
cd frontend
npm install
npm install react-router-dom@latest axios@latest
```

### Flutter / Mobile Projects
```bash
flutter create project_name
cd project_name
flutter pub upgrade --major-versions
```

### Python / AI Projects
```bash
python -m venv venv
source venv/bin/activate
pip install anthropic langchain openai python-dotenv fastapi uvicorn
pip freeze > requirements.txt
```

### Angular Projects
```bash
npx @angular/cli@latest new project-name
cd project-name
npm install
```

### Vue Projects
```bash
npm create vite@latest project-name -- --template vue
cd project-name
npm install
```

## Rule 11 — Neumorphism (Soft UI) Design System Mandate

All user interfaces across this project MUST strictly follow the **Neumorphism (Soft UI)** design system:
- **Base Surface / Background**: `#E0E5EC` (Cool Clay). Never use pure `#FFFFFF` page backgrounds.
- **Primary Text**: `#3D4852` (High contrast cool grey/slate).
- **Muted Text**: `#6B7280` (WCAG AA compliant).
- **Accent Highlight**: `#6C63FF` (Soft Violet) & `#38B2AC` (Teal).
- **Extruded Shadow (Default)**: `box-shadow: 9px 9px 16px rgba(163,177,198,0.6), -9px -9px 16px rgba(255,255,255,0.5)`
- **Extruded Hover (Lifted)**: `box-shadow: 12px 12px 20px rgba(163,177,198,0.7), -12px -12px 20px rgba(255,255,255,0.6)`
- **Inset Shadow (Pressed)**: `box-shadow: inset 6px 6px 10px rgba(163,177,198,0.6), inset -6px -6px 10px rgba(255,255,255,0.5)`
- **Inset Deep Shadow (Inputs/Wells)**: `box-shadow: inset 10px 10px 20px rgba(163,177,198,0.7), inset -10px -10px 20px rgba(255,255,255,0.6)`
- **Container Rounding**: `32px` (`rounded-[32px]`), Buttons: `16px` (`rounded-2xl`).

## Rule 12 — Autonomous Creation & Clarify AI Co-Founder Query Protocol (MCP Connection)

When building or working on a project generated by ClarifyAI:
1. **Continuous Co-founder Query Loop**: If an external AI agent (e.g., Antigravity, Claude Code) is connected via MCP, it MUST continuously query Clarify AI co-founder (`clarifyai_ask_cofounder`, `clarifyai_get_next_step`, `clarifyai_get_project_context`, `clarifyai_get_all_documents`) step-by-step until the project is 100% fully built and complete.
2. **Complete Execution Without MCP**: If MCP is not connected, the agent must build the entire end-to-end working project completely along with live preview links before completing the turn.
3. **Persistent Chat History**: All questions and answers exchanged between the AI agent and Clarify AI co-founder MUST be recorded and saved in the project's AI Chat History (`ProjectChat` / backend `ChatMessage`) persistently until explicitly deleted by the user.
4. **Document Grounded Intelligence**: Clarify AI must read and inspect all project documents (PRD, Architecture Specs, API Contracts, Design System, Kanban Tasks) to provide accurate, context-aware answers.
